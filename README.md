# 图片批量压缩

> 在「不忙脚本盒子」中一键批量压缩图片：支持 JPEG / PNG / WebP / AVIF 四种格式互转，内置 MozJPEG 深度优化，画质更佳、体积更小，也可作为节点被其他脚本调用。

---

## 核心特性

- **一键批量压缩**：右键选中一张或多张图片即可批量处理，压缩结果自动保存回原目录
- **四种格式互转**：JPEG / PNG / WebP / AVIF 任意输入输出，选择不同格式即完成格式转换
- **MozJPEG 深度优化**：JPEG 采用 MozJPEG 编码，同等画质下体积更小
- **PNG 无损压缩**：最高压缩等级 + 自适应过滤，无损且体积更小
- **WebP / AVIF 支持**：现代高压缩率格式，进一步缩小图片体积
- **参数灵活可调**：压缩质量、输出格式、最大边长均可在启动窗口中即时调整
- **可作为节点**：其他脚本可通过盒子接口同步调用，返回压缩结果路径

## 安装方法

本脚本的运行环境、依赖组件及启动窗口均依赖「不忙脚本盒子」，建议仅通过盒子安装和使用。

> 前置条件：已安装 [不忙脚本盒子](https://www.bm-box.cn)

1. 打开盒子 → **脚本市场**
2. 搜索 **「图片批量压缩」**
3. 点击「安装」

---

## 使用方式

### 右键菜单

1. 在文件管理器中选中一张或多张图片
2. 右键 → 「不忙脚本盒子」→「图片批量压缩」
3. 在启动窗口中按需调整参数（默认值已填好），点击执行即可

### 快捷键

1. 在盒子的「热键管理」页面为本脚本设置全局快捷键
2. 选中图片后按下快捷键，即可快速启动压缩

### 输出位置

压缩结果保存在**原图片所在目录**，文件名为 `原文件名_compressed.{扩展名}`，扩展名随所选输出格式变化：

| 输出格式 | 扩展名 | 示例（源 `photo.png`） |
| --- | --- | --- |
| JPEG | `.jpg` | `photo_compressed.jpg` |
| PNG | `.png` | `photo_compressed.png` |
| WebP | `.webp` | `photo_compressed.webp` |
| AVIF | `.avif` | `photo_compressed.avif` |

## 💡 使用提示

- **压缩质量**：取值 1~100，数值越高画质越好、体积越大；JPEG / WebP / AVIF 建议 70~85，PNG 为无损压缩不受质量影响。
- **输出格式**：与源图格式相同则仅做压缩；选择不同格式即同时完成格式转换。
- **最大边长**：填 `0` 表示保持原尺寸；填 `1920` 等数值会等比缩小超过该边长的图片。
- **同名覆盖**：输出文件与源文件同目录，若同名文件已存在会被直接覆盖，请留意。

## 节点脚本（开发者阅读）

本脚本已声明为节点（`node`），其他脚本可通过盒子 `/api/link` 同步调用，返回业务键：

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `output_paths` | list | 压缩成功后的图片绝对路径列表 |
| `failed` | list | 处理失败的文件及原因，元素形如 `{file, error}` |

返回信封示例：

```json
{ "code": 0, "msg": "成功 3 个，失败 0 个", "output_paths": ["C:/a_compressed.jpg"], "failed": [] }
```

此外，直接执行 `node main.js`（不带参数）可打开独立预览界面，支持拖拽、原图/压缩后实时对比，便于单张调参。
